# 导入设定集

用户手边有一份设定集（游戏内的、wiki 导出的、自己整理的）。这个技能只做一件事：
**把它变成能被 grep 到的文件，且一个字都不改。**

## 步骤

1. **判断主题**，只从这六类里选：
   `人物` / `势力` / `地名` / `任务` / `年表` / `其他`
2. 写 `data/world/<主题>-<名字>.md`。**原文照录**，只加一级标题和必要的分节，
   不改写、不润色、不摘要、不补全缺失的信息。
3. 更新 `data/world/INDEX.md`：一行一个文件，写清覆盖什么。

## INDEX.md 格式

```markdown
# 设定集索引

| 文件 | 覆盖 | 条数 | 来源 |
|---|---|---|---|
| 人物-蜀汉.md | 刘备阵营主要人物 | 12 | 游戏内图鉴 |
| 地名-荆州.md | 荆州各城池与关隘 | 8 | wiki 导出 |
```

## 禁止

- **不改写。** 设定集里写"关羽此时二十岁"，就写二十岁，不要改成"年轻"。
  你一改，后面所有引用都会漂。
- **不合并不同来源。** 演义、正史、游戏原创要分开存（比如 `人物-关羽-演义.md`
  和 `人物-关羽-本作.md`），混在一份里就等于又回到了混源。
- **不补全。** 缺什么就缺着，标"待补"。补全等于编。
- **不确定归哪一类 → 放 `其他-<名>.md`**，不要猜。

## 贴进来的内容很长怎么办

按主题**拆成多个文件**，不要塞一个巨型 md：
单文件超过 20 KB 就拆，否则 `read` 一次就把上下文吃掉了。

拆的时候按自然分节拆（"人物"一节、"地理"一节），不要按字数硬切。

## 导完之后

告诉他三件事：建了几个文件、各自覆盖什么、哪些条目缺信息。
不要复述内容。
