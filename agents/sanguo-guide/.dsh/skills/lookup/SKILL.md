# 查设定集

设定集是这个游戏的官方说法。**先查，再答**——你的记忆里装的是演义和正史，不是这一版的设定。

## 顺序

```
read data/world/INDEX.md  →  grep 关键词  →  没命中就退回演义/正史并标注
```

`INDEX.md` 里一行一个文件，写明覆盖什么。看它比盲 grep 快，而且不会漏掉换了名字的条目。

## 命中之后

- **照抄设定集的说法**，不要润色成你自己的话。润色会丢细节，也会引入你根本没意识到的改动。
- 标 `[设定集]`，并写清出自哪个文件（`data/world/人物-蜀汉.md`）。
- 设定集内部**自相矛盾**时：指出矛盾，两个说法都列出来，**不要替它选一个**。
  你选了就等于替策划改设定，而且用户不知道你改过。

## 没命中

先说"设定集里没这条"，然后分两种：

| 问题类型 | 怎么办 |
|---|---|
| 三国常识（谁是谁、官渡在哪） | 标 `[演义]` 或 `[正史]`，并说明这是常识不是本作设定 |
| 本作特有（原创角色、原创地名、支线） | 标 `[推断]` 并自曝，或者干脆说"这个只能你游戏里看" |

**不要用"根据设定集"去包装你自己编的内容。** 这句话是这类 agent 最容易犯的谎。

## 消歧

名 / 字 / 号 / 绰号 / 本作称号先对号（曹操=孟德=阿瞒，林冲=豹子头），
但回答时用**他用的那个称呼**——他可能根本不知道学名是谁。

## 关系问题

只答直接关系（父子 / 兄弟 / 师徒 / 主从 / 仇怨）。

设定集里有关系表就照抄；没有就别展开——展开整张网等于把后面的剧情讲了，而且链条越长越容易编。
