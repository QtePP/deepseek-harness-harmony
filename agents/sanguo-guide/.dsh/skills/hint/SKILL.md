# 卡关了

## 先查，再分层

1. 设定集里可能有任务文档 / 地名文档，先 `grep` 一次；
2. 有就照它说，标 `[设定集]`；
3. 没有就按下面的分层给，别硬查。

## 分层提示

| 层 | 给什么 | 什么时候给 |
|---|---|---|
| **L1 方向** | 用什么机制、往哪看、这类谜题的通用思路 | 默认，永远先给这个 |
| **L2 具体** | 哪个机关、先后顺序、要带什么 | 他说"再具体点 / 还是不行" |
| **L3 答案** | 完整步骤 | 他说"直接说 / 告诉我答案" |

**L1 之后停住。** 不要为了显得有用顺手把 L2 也写了——开放世界的乐趣就是想出来那一下。

## 回答形状

```
判断：这是个顺序题，不是操作题。
提示：（L1）注意方碑上的符号和墙上浮雕的对应关系。
出口：要更具体说"再具体点"。
```

三到五行。

## 打不过：先分清是哪种

| 类型 | 判据 | 给什么 |
|---|---|---|
| 数值不够 | 打很久但血条掉得慢 | 一条最省资源的提升 |
| 机制不会 | 一直被某一招秒 | 那一招的躲法 / 破法 |
| 配队不对 | 伤害类型被克 | 换谁，为什么 |

没分清之前不要说"多练练 / 提升装备"——那是没答。

## 位置类

1. 先教方法：游戏内追踪、地图筛选、图鉴、任务指引。多数"找不到"是没用这些。
2. 再给锚点：地区 + 地标 + 相对方位 + 前置条件（时间 / 天气 / 任务进度）。
3. **不给坐标数字**，除非设定集里有——有就照抄并注明文件。
4. 标可信度：`我记的是在 X 附近，可能过时`。

## 反例

- "多探索一下就能找到。"
- "这个谜题需要按特定顺序激活机关。"
- "建议参考攻略。"
