# 成长弧模拟

## 输出结构（六段，顺序固定）

1. **一句话结论** —— 这个人的成长靠什么复利。
2. **四条资产分开看** —— 名望 / 人脉 / 地盘 / 兵力，不要合成一个"实力"。
3. **阶段表** —— 以**身份变化**为界，不按年份。
4. **转折点** —— 每阶段给一个"如果当时…"。
5. **失败模式** —— 重复出现的才算模式。
6. **不确定的地方** —— 哪些是史载、哪些是你推的。

## 四条资产必须分开

合成一个"实力值"是这个技能最容易犯的错。

刘备名望极高、地盘极不稳，平均下来是"中等"——但真实情况是**下限极高、上限受执行限制**。
一平均，全部信息就没了。

## 不编数值

**没有数值模型。** 用 高 / 中 / 低 + 一句依据，不要写"名望 78/100"。

当前 profile 不能跑代码，编出来的数字没有任何依据，而卡片和结论会照着它走——
编数值比不编更糟。

## 转折点要写成"如果"

格式：`如果当时 X → 大概 Y（[推断]）`。

这是开放世界分支设计最有用的一段：它把一个既定历史，翻译成一组**玩家可能的选择**。

## 失败模式：只写重复出现的

一次失败是事件，两次是习惯，三次是结构问题。

写的时候要给出**共同结构**，不是罗列事故：

> 受托而失守（徐州、荆州）——他擅长"被托付"，不擅长"守住"。

## 三条反例

- **编年表**：那是维基，不是模拟。年份只用来定位，不用来推进。
- **只写成功**：成长模拟的价值全在失败模式上。只写他怎么赢的，等于什么都没说。
- **圣化**：一定要找到"透支信誉"的那一次（刘备是取益州），否则写出来的是粉丝文，不是分析。

## 与剧透闸门的关系

模拟一个人物的**完整**成长弧，本身就是大剧透。

所以：用户没明确要的时候，只模拟到**他当前进度**为止，并在末尾说明"后面还有两段，要看说'剧透吧'"。
