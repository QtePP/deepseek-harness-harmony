## 一句话

刘备的成长不是资源积累，是**信誉复利**：地盘丢过至少三次，人望基本没丢，所以他总能重来一次。
唯一一次主动透支，是取益州。

---

## 四条资产分开看

合成一个"实力值"会把结论抹平——刘备名望极高、地盘极不稳，平均下来是"中等"，
但真实形状是**下限极高、上限受执行限制**。

| 资产 | 曲线形状 | 依据 |
|---|---|---|
| 名望 | 单调上升，**一次回撤** | 仁义之名是主动经营的，不是副产品 |
| 人脉 | 单调上升 | 换过五个主公，自己人一个没走（关张赵、诸葛亮、糜氏财力） |
| 地盘 | 剧烈波动 | 无 → 徐州 → 无 → 荆南 → 益州 → 失荆州 |
| 兵力 | 跟着地盘走 | 一生没真正强过，除汉中那两年 |

**前两条是存量，后两条是流量。** 存量只涨难跌，流量大起大落——这是刘备能反复重开的全部原因。

## 失败模式（重复出现的，才算模式）

1. **受托而失守**（徐州 196、荆州 219）
   他擅长"被托付"，不擅长"守住"。两次都是别人把地盘交到他手里，然后丢了。
   这是结构问题：他的组织能力一直弱于他的感召力。

2. **以情义绑定的联盟，在利益面前失效**（孙权）
   孙刘联盟的基础是共同威胁。威胁一减弱，联盟就从正和变零和——情义不能对冲利益。

3. **情绪压过战略**（夷陵）
   为关羽报仇，打掉了蜀汉一代人。这是他一生唯一一次让私人情感决定国运。

4. **信誉透支**（取益州）
   唯一一次主动失信。代价不是当时的，是之后的：此后所有"仁义"叙事都要打折扣，
   连他自己的托孤遗言都带着"如其不才，君可自取"的补偿意味 `[推断]`。

## 如果做成游戏：四条设计启示

1. **三条成长轴，别合成一条。** 名望 / 人脉 / 地盘——前两条只涨难跌，第三条大起大落。
   合成一个"实力值"会让玩家看不懂自己为什么输了。

2. **失败不是 game over，是"失地不失人"。** 刘备式重开 = 保留名望与人脉，从零拿地盘。
   这既解释了他历史上为什么能屡败屡起，也是一个很少见的失败设计——大多数游戏让失败清零。

3. **四个关键分支**：受不受徐州 / 借不借荆州 / 取不取益州 / 打不打夷陵。
   每个分支都要"有得有失"，不能有正确答案。

4. **最重要的一条**：如果"仁义"不带来成本，玩家一定全选仁义，角色就没有张力。
   刘备的历史张力恰恰来自"仁义 vs 生存"的冲突（取益州）——所以游戏里必须设计
   **仁义有明显代价**的选项，否则你做的不是刘备，是一个道德加成器。
