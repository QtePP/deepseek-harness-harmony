# 刘备偏离推演（`what-if` 技能的实跑示例）

> **全文剧透。** 这是技能示例输出，不是任何游戏的官方设定，也不能进 `data/world/`。
> 标注：`[演义]` / `[正史]` / `[推断]`（本文的推演判断）。

---

## 先钉基线：两处偏离点，两个完全不同的处境

| 偏离点 | 历史基线（`[正史]`） | 名义身份 |
|---|---|---|
| 200 年 | 衣带诏事泄，刘备据徐州、杀车胄、连袁绍；曹操亲征，败走，投袁绍 | 左将军、豫州牧——**汉臣** |
| 214 年 | 刘璋迎其入蜀拒张鲁，212 反目，214 围成都，刘璋降 | 左将军、荆州牧，自领益州牧 |

**一个容易被忽略的事实**：200 年他其实已经反曹了，所以"自立"这个偏离，**不是"要不要反"，
而是"要不要公开称制"**——历史上他到死都没称帝（称帝是 221 年，且是曹丕代汉之后）。
把偏离点定准，推演才有意义。

---

## 偏离 A：200 年公开称制

**偏离内容**：不止据徐州，而是承制封拜、建国号，与许都彻底决裂。

### 三链传导

| 链 | 变化 |
|---|---|
| 正当性 | 从"汉臣 + 宗亲"变成**"第二个袁术"**。袁术 197 年称帝、199 年败死，尸骨未寒 `[正史]` |
| 联盟 | 袁绍乐见曹操多一个敌人，但**不会承认他的名号**（袁绍自己有想法）；刘表是汉室宗亲，最忌讳别人抢先称制；孙权 200 年刚继位（19 岁），只会观望 |
| 资源 | 短期动员力上升（建国能募兵、能许诺官爵）；徐州四战之地、根基极浅，消耗同时上升 |

**最关键的是第一条。** 刘备一生不可替代的资产是"仁义 + 宗亲"这个组合，称制是一次性把它花掉——
而且**信誉资产跌了不会自己涨回来**，这跟地盘不一样。

### 三段后果

**近期（3–6 个月）**：曹操必亲征，而且这次有了"讨逆"的名义，师出更顺。
历史上田丰劝袁绍趁曹操东征袭许都，袁绍以子病辞 `[正史]`——称制不太可能改变这个判断，
因为袁绍自己正在准备官渡。所以**期待中的外援大概率不会来** `[推断]`。

**中期（1–2 年）**：徐州守不住（历史已经证明）。真正的差别在**退路**：
历史上他能投袁绍、投刘表，因为他顶着"汉臣、衣带诏义士"的名分。
称制之后，刘表大概率不收（宗亲称制是他最不能容忍的事），袁绍可能收，但会削其兵权 `[推断]`。

**分水岭**：他变成第二个袁术——有兵、无盟友、无正当性。
再往后不是"能不能成大业"的问题，是"能不能活下来"的问题。

### 代价落到具体的人

不是"失去民心"，是：**糜竺会犹豫**。糜竺押上的是徐州豪族的全部身家，
他投的是"汉室宗亲刘使君"，不是一个新朝的开国之主——这两者的风险差一个量级 `[推断]`。

### 结论

这个偏离的代价**不是军事的，是叙事的**。
收益是短期动员力与"名正言顺"，代价是长期联盟与信誉。而在这个时代，后者比前者贵。

## 偏离 B：不取益州

**偏离内容**：214 年止步荆州，不入蜀。

### 三链传导

| 链 | 变化 |
|---|---|
| 战略 | 隆中对"跨有荆益、两路北伐"不成立。一州对两强（北曹操、东孙权） |
| 联盟 | 孙权对荆州的诉求不会因为他讲义气而消失。历史上 215 年孙权就派吕蒙取三郡 `[正史]`；不取益州，刘备没有"西部补偿"可给，索要只会更早更硬 |
| 正当性 | **唯一净收益**：仁义品牌完整。取益州是他一生唯一一次主动失信 |

### 三段后果

**近期**：刘璋仍在，益州内耗（北有张鲁，东州派与本土派矛盾）。
曹操 215 年取汉中后会顺势南下——历史上正是因为刘备夺了益州，才在汉中挡住了这一波 `[正史]`。

**中期**：荆州压力剧增。没有西部纵深，荆州就是唯一的家底，
而荆州北有襄阳、东有孙权，是标准的四战之地。孙权索荆州的时间会提前、力度会加大 `[推断]`。

**分水岭**：荆州大概率在 215–217 之间易手（比历史早 2–4 年）。
之后刘备要么退往南中 / 交州，要么彻底沦为孙权的附庸。

### 结论

收益是道德资本，代价是**生存空间**。
而这个世界的结构决定了：**道德资本不能换地盘**——它只能换来"下次还有人愿意跟你"，
换不来这一仗的粮草。

## 两个偏离，其实是同一枚硬币

| | 200 称制 | 不取益州 |
|---|---|---|
| 动的是 | 提前花掉信誉 | 保住信誉 |
| 换来的是 | 合法性与动员力 | 道德资本 |
| 放弃的是 | 联盟与退路 | 战略空间 |

两个偏离都在动同一组变量：**合法性 / 空间 / 信誉**。三者不可同时要。

而刘备真实的选择（不称制、取益州），恰好是"**延迟花信誉、优先买空间**"——
这不是道德选择，是生存选择。后人把它读成仁义，是因为结果恰好体面。

**如果两个偏离一起做**（200 称制 + 不取益州）：信誉已经花掉，空间也放弃，
既没有盟友也没有纵深——这是最差组合，几乎必然提前出局 `[推断]`。

---

## 给游戏设计的三条

1. **三个变量要变成可见资源**：合法性 / 空间 / 信誉。玩家看不见的东西，他不会权衡，
   只会觉得"怎么突然就输了"。
2. **偏离必须有即时收益**。只给代价的偏离没人会选，那不叫自由，叫陷阱。
   200 称制的即时收益是动员力，不取益州的即时收益是口碑——两个都真实，只是长期不划算。
3. **不要用历史惯性把玩家拽回去**。如果玩家 200 年称制、结果官渡还是照原样打完，
   那这次偏离就是假的，玩家会立刻发现你在骗他。
