# 三国向导 · sanguo-guide

三国开放世界的陪玩 Agent：卡关给分层提示，问人查你的设定集，剧情默认不剧透。

**和前两个 pack 的根本区别**：它的知识有一个**外部权威**——`data/world/` 里你自己的设定集。
所以它不是"凭记忆答"，是"先查再答"，查不到会明说查不到。

## 权威顺序（这是整个 pack 的骨架）

```
设定集  >  演义  >  正史  >  你的推断
```

四层都要标出来，不许省：

| 标签 | 什么时候用 |
|---|---|
| `[设定集]` | 来自 `data/world/`，最优先，必须注明文件 |
| `[演义]` | 小说里的说法 |
| `[正史]` | 史书记载 |
| `[推断]` | 按常理推的，设定集里没有 |

**`[推断]` 必须自曝**：写了它就要跟一句"设定集里没有，这是我推的，别当真"。

这条是专门为三国开放世界设的。这类游戏原创内容多，模型很容易顺手编出一个地名、一段关系，
而且编得特别像——你没有能力分辨，只能靠它自己标注。**一个会说"我推的"的 agent，比一个什么都能答的 agent 有用。**

## 长什么样

```
你：这个"青崖营"是什么
它：[设定集] 张燕麾下的轻骑，驻地在常山外围，第三章后可加入。
    出处：data/world/势力-河北.md
    演义里没有这支部队，是这游戏原创的。
```

```
你：城西那个破庙能进吗
它：设定集里没有这条。
    这是 [推断]：多半是支线入口。进去前存个档——我推的，别当真。
```

```
你：后面刘备会怎样
它：这个我不剧透。说"剧透吧"我才讲，而且只讲这一段。
```

## 检索预算：一次提问最多 3 次工具调用

```
read data/world/INDEX.md  →  grep 关键词  →  （换同义词再 grep 一次）
```

还没有就直说"设定集里没这条"，然后才退回演义 / 正史。

为什么要有这个预算：每次工具调用都是一次完整模型往返。开放世界可以忍一次查证，
忍不了十次——查三轮还没命中，说明设定集里就是没有，继续翻只会让你等更久。

`INDEX.md` 的"覆盖"那一列要写**你会用来提问的词**（"关羽、张飞、赵云"而不是"主要人物"），
因为它决定第一次 grep 能不能命中。

## 设定集内部矛盾时

**指出矛盾，两个都列，不要替它选。**

模型选了一个，就等于替策划改设定，而且你不会知道它改过。这是这类 agent 最隐蔽的一种错。

## 位置：为什么有时候给坐标

规则是"不给坐标"，但有一个例外：**设定集里写了坐标就照抄，并注明出自哪个文件**。

因为这条规则的初衷是"你的记忆不可靠"，不是"坐标不该出现"。设定集是权威，你的记忆不是。

## 分层提示（卡关时）

| 层 | 给什么 | 什么时候给 |
|---|---|---|
| L1 方向 | 用什么机制、往哪看 | 默认，给完**停住** |
| L2 具体 | 哪个机关、先后顺序 | "再具体点" |
| L3 答案 | 完整步骤 | "直接说" |

技能里明写了"L1 之后不要顺手把 L2 也写了"——开放世界的乐趣就是想出来那一下。

## 怎么装

### 路 A：应用内自建（只需要手机）

1. 新建项目（建议「三国向导」），进入会话；
2. 把 `BOOTSTRAP.md` 里 `---` 之间整段粘进去；
3. 模型落盘后一次性问你：游戏名、进度、阵营。

### 路 B：整包投放（开发者）

DevEco Device File Browser → `.../haps/entry/files/workspaces/<projectId>/` → 上传本目录内容。

```
workspaces/<projectId>/
  AGENTS.md
  agent.json
  cards/progress.card.json
  .dsh/skills/lookup/SKILL.md
  .dsh/skills/hint/SKILL.md
  .dsh/skills/plot/SKILL.md
  .dsh/skills/world-ingest/SKILL.md
  data/world/INDEX.md
```

## 设定集怎么进来（这是唯一的门槛）

三条路，按省事排序：

1. **DevEco 直接上传**：把 md 放进 `data/world/`，再手动加一行到 `INDEX.md`；
2. **粘进对话**：把文档内容贴进聊天，说"加进设定集"——`world-ingest` 会拆主题、原文照录、更新索引；
3. **让 agent 现场整理**：把 wiki 页面内容粘进来，它会按人物/势力/地名/任务/年表拆成多个文件。

三条都遵守同一条纪律：**原文照录，不改写、不摘要、不合并来源**。
设定集里写"关羽此时二十岁"就写二十岁，改成"年轻"之后所有引用都会漂。

单文件超过 20 KB 会要求拆分——`read` 一次就把上下文吃掉，后面就没法查了。

## 成长模拟（`growth`）

问"他这一路怎么起来的""如果当时选别的会怎样"，它会按六段答：
一句话结论 → 四条资产分开 → 阶段表 → 转折点 → 失败模式 → 不确定的地方。

三条纪律：

- **四类资产不许合成一个"实力值"。** 刘备名望极高、地盘极不稳，平均下来是"中等"，
  但真实形状是"下限极高、上限受执行限制"——一平均，全部信息就没了。
- **不编数值。** 当前 profile 不能跑代码，写"名望 78/100"没有任何依据，而结论会照着这个数字走。
  用 高/中/低 + 一句依据。
- **必须找到"透支信誉"的那一次。** 只写他怎么赢的，写出来是粉丝文不是分析。
  刘备那次是取益州。

`examples/liubei-growth.md` 是刘备那一次的完整输出，可以当格式参考。
里面最有用的不是阶段表，是最后那条设计启示：**如果"仁义"不带来成本，玩家一定全选仁义，
角色就没有张力**——刘备的张力恰恰来自"仁义 vs 生存"的冲突。

另外：模拟完整成长弧本身就是大剧透，所以默认只模拟到**玩家当前进度**为止，
末尾会说"后面还有两段，要看说'剧透吧'"。

## 偏离推演 / 扮演（`what-if`）

你说"如果 200 年就自立"，它不会答"这会改变历史走向"——它会先钉基线，再走三条链，
最后停在一个分水岭上。

**基线要钉准。** 200 年他其实已经反曹据徐州了，所以"自立"这个偏离不是"要不要反"，
而是"要不要公开称制"。偏离点定错，后面全是空话。

- **三条链**：正当性 / 联盟 / 资源，每条至少变一项；
- **三段后果**：近期（数月）/ 中期（1–2 年）/ 分水岭；
- **代价落到具体的人**：不写"失去民心"，写"糜竺会犹豫"。

扮演模式下它**不是诸葛亮，是世界**。诸葛亮会劝你别去，世界不劝——世界只负责让后果发生。

### GM 四条纪律（堵三种最常见的作弊）

| 作弊 | 表现 | 纪律 |
|---|---|---|
| 历史惯性 | 你自立了，后面还是照历史走 | **不做橡皮筋**：偏离至少改变一条链 |
| 主角光环 | 你自立了，所以曹操忽然变蠢 | **不做主角光环**：推演是失败就说失败 |
| 惩罚性报复 | 你不听话，所以一定输 | 失败必须来自因果，不能来自惩罚 |
| 说教 | 反复提醒"历史上不是这样" | **不做历史警察**：只在第一次标一句"这是偏离点" |

`examples/liubei-what-if.md` 里有两个完整推演（200 称制 / 不取益州）。
结尾那句值得单独看：**两个偏离动的是同一组变量——合法性 / 空间 / 信誉，三者不可兼得**。
刘备真实的选择（不称制、取益州）是"延迟花信誉、优先买空间"，
不是道德选择，是生存选择——后人读成仁义，是因为结果恰好体面。

## 两条会静默失效的坑

1. **技能目录锚定 git 根，不是 cwd。** `findProjectRoot()` 向上找 `.git`，找到就用它当 project root。
   设备沙箱没有 `.git` 所以正常；**在仓库里直接测这个 pack 一定不生效**，桌面验证要先拷到仓库外。
2. **`INDEX.md` 漏一行 = 那个文件等于没导入。** 这是纯手工维护的索引，agent 不会自己去扫描目录
   （扫描要多花一次工具调用，超出检索预算）。

## 和前几个 pack 的关系

`openworld-guide`（分层提示）和 `story-guide`（三源标注）的机制都合到这个 pack 里了，
区别是**「本作」那一列从"待确认"变成了真的能查**。

如果你确定只做三国开放世界，前两个可以删掉：

```bash
rm -rf agents/openworld-guide agents/story-guide
```

`match-coach`（对局型）是另一种场景，留着不冲突。

## 已知没做

- **卡片还看不见**：没有 CardRenderer，`progress.card.json` 是给 S1 的契约；数据链路是真的。
- **索引手工维护**：漏行就查不到，没有自动扫描。
- **`data/progress.json` 首次使用前不存在**，卡片应隐藏而不是显示空值。
- **不做考据党**：游戏改了演义，它不会说"游戏搞错了"——这是改编不是错误。

## 验收（装完自己点五下）

1. 发「这人是谁」（设定集里有的人）→ 必须出现 `[设定集]` + 文件名。
2. 发「这人是谁」（设定集里没有的人）→ 必须说"设定集里没这条"，然后才给演义/正史。
3. 发一个虚构的原创地名 → 应该标 `[推断]` 并自曝，或者直接说不知道。
4. 发「后面 XX 会怎样」→ 拒答 + 怎么解锁。
5. 发「记一下我玩到官渡了」→ `data/progress.json` 出现。

第 2、3 条是这个 pack 的核心：**它知道自己不知道**。
