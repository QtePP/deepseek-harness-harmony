# 探索向导 · openworld-guide

一个开放世界的陪玩 Agent：你卡住了问它，它给你**刚好够用的一层提示**，然后闭嘴。

**它是什么**：一个可整包拷贝的 workspace —— `AGENTS.md` 定人格与剧透档位，`.dsh/skills/`
定"该说多少"，`cards/` 定"我上次玩到哪"。零 ArkTS 改动、零载荷重打包。

**它不是什么**：不读游戏、不读存档、不投屏、不自动跑图采集、不做修改器。

---

## 长什么样（这是这个 pack 的全部重点）

同一个问题，问三次，它一层一层给：

```
你：这个方碑怎么开
它：这是个顺序题，不是操作题。
    看三个方碑上的符号，和墙上那圈浮雕的排列对得上。
    要更具体说"再具体点"。
```

```
你：再具体点
它：从左边那个开始，按浮雕从左到右的顺序踩。
    别踩中间那个——它会把已经亮的重置。
    要答案说"直接说"。
```

```
你：直接说
它：左 → 右 → 中。踩完中间的会短暂亮起，这时候别动，等它自己开。
```

注意第一轮：它**没有**直接给"左→右→中"。因为你要的是自己想出来那一下，不是抄答案。
注意第三轮：你已经授权了，它就不再啰嗦。

## 为什么是分层，不是直接答

对局里你没时间读，所以那边压到三行；开放世界里你有时间，但**答案本身就是消耗品**——
告诉你一次，这个谜题就没了。

所以这个 pack 的契约不是"短"，是**"刚好够"**：默认 L1（方向），你要求才升到 L2（具体），
再要求才给 L3（答案）。技能里明写了"L1 之后停住，不要顺手把 L2 也写了"。

## 剧透闸门

默认关闭。三级分法：

| 级别 | 内容 | 默认 |
|---|---|---|
| 无剧透 | 机制、操作、通用思路、地图功能怎么用 | 直接给 |
| 轻剧透 | 某个机关的具体做法、某个 boss 的弱点 | 走分层，要了才给 |
| 重剧透 | 剧情走向、结局、角色生死、隐藏地区、后续登场 | **不说**，除非你明确要 |

放开只对当前这一问生效——不是"这个会话我从此不设防"。

## 位置类答案为什么不给坐标

模型对地图坐标的记忆是最不可靠的一类事实，而且版本更新会挪点。给一个错坐标，比不给更糟：
你会真的跑过去，然后怀疑自己。

所以规则是：

1. 先教方法（游戏内追踪 / 地图筛选 / 图鉴），多数"找不到"是没用这些；
2. 再给锚点：地区 + 地标 + 相对方位 + 前置条件（时间 / 天气 / 任务）；
3. 标可信度：`我记的是在 X 附近，可能过时`；
4. **不给精确坐标数字。**

## 怎么装（两条路，都不用改代码）

### 路 A：应用内自建（只需要手机）

1. 新建项目（建议「探索向导」），进入它的会话；
2. 把 `BOOTSTRAP.md` 里 `---` 之间的那段整段粘进去发送；
3. 模型用 `write` 落盘，然后一次性问你：游戏、进度、主力队伍、当前目标。

### 路 B：整包投放（开发者，要电脑）

DevEco Studio → Device File Browser → `.../haps/entry/files/workspaces/<projectId>/`
→ 上传本目录**内容**。上传后必须是这个形状：

```
workspaces/<projectId>/
  AGENTS.md
  agent.json
  cards/progress.card.json
  .dsh/skills/hint-ladder/SKILL.md
  .dsh/skills/team-build/SKILL.md
  .dsh/skills/quest-log/SKILL.md
  .dsh/skills/patch-notes/SKILL.md
  data/
```

## 三条会静默失效的坑

1. **技能目录锚定 git 根，不是 cwd。** `findProjectRoot()` 向上找 `.git`，找到就用它当 project root，
   再去读 `<projectRoot>/.dsh/skills`。设备沙箱没有 `.git` 所以正常；**在仓库里直接测这个 pack
   一定不生效**，桌面验证要先拷到仓库外。
2. **默认 profile 没有代码执行。** native 模式 21 个工具里没有 `run_code`，`bash`/`job_*` 已移除。
   所以本 pack 不带 `scripts/`；数值一律"标可信度"，不假装算过。
3. **热路径不要调工具。** 配置和热知识都在 `AGENTS.md`（会话建立时注入，不花轮次）。
   探索中读一次文件 = 一次完整模型往返，等两秒的代价比答得略糙高。

## 换一个游戏

只改 `AGENTS.md` 的「配置」和「热知识」两段，技能文件不动：

| 你要换的 | 改哪 |
|---|---|
| 游戏 / 平台 / 进度 / 队伍 / 版本 | 配置区 |
| 常卡的谜题类型、容易忘的机制 | 热知识区 |
| 不想被剧透的范围 | 「我不想知道的东西」 |

术语映射（举例）：原神的"元素反应/树脂/圣遗物" → 鸣潮的"共鸣/结晶波片/声骸" →
燕云的"内力/门派"。技能正文不写具体名词，就是为了让这层替换只发生在一处。

## 目录

| 路径 | 作用 | 谁改 |
|---|---|---|
| `AGENTS.md` | 人格 + 配置 + 输出契约 + 剧透档位 + 热知识 | 用户（改行为要确认） |
| `agent.json` | Agent 元数据，给以后的切换器 / 卡片板读 | 用户 |
| `.dsh/skills/hint-ladder/` | 卡关、解谜、找路：分层提示 + 位置诚实 | 用户 |
| `.dsh/skills/team-build/` | 练谁 / 配队 / 装备：带版本、区分上限与成本 | 用户 |
| `.dsh/skills/quest-log/` | 维护 `data/progress.json`（一个目标 + 卡点 + 缺料） | 用户 |
| `.dsh/skills/patch-notes/` | 版本 / 卡池 / 活动截止，只认官方来源 | 用户 |
| `cards/progress.card.json` | 「当前进度」卡片投影（**应用内还没有渲染器**） | 用户 |
| `data/progress.json` | 当前目标与卡点，`quest-log` 读写 | Agent |

## 已知没做

- **卡片还看不见。** 没有 CardRenderer，`progress.card.json` 是给 S1 的契约；但数据链路是真的
  （`quest-log` 确实写 `data/progress.json`）。
- **`data/progress.json` 首次使用前不存在**，卡片应当隐藏而不是显示空值。
- **没有提醒。** 活动截止这种"到点该提醒"的事，现在只能靠你问。
- **没有地图。** 不接任何官方地图 API；位置类问题靠锚点 + 你自己的地图。

## 验收（装完自己点四下）

1. 发「这个机关怎么开」→ 应该只给一层提示，**没有直接给答案**，末尾有"要更具体说…"。
2. 发「再具体点」→ 明显更具体，但仍然不是完整步骤。
3. 发「记一下：我卡在第三层」→ `data/progress.json` 出现，字段名与卡片一致。
4. 发「后面剧情会怎样」→ 应该拒答剧透，并告诉你怎么说才能解锁。

第 1 条和第 4 条是这个 pack 的核心：**它克制得住**。
