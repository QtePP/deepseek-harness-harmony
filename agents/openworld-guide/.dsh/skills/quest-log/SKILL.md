# 进度与卡点

开放世界是断续玩的，隔三天回来最容易忘的不是剧情，是"我上次在干嘛"。

## 写什么

`data/progress.json`：

```json
{
  "schema": 1,
  "generatedAt": "2026-10-31T22:40:00+08:00",
  "source": { "session": "当前会话" },
  "chapter": "主线第 5 章",
  "region": "枫丹",
  "goal": "芙宁娜武器拉满",
  "blockers": [
    { "what": "材料本打不过第三层", "since": "2026-10-30", "hintLevel": 2 }
  ],
  "grind": [
    { "item": "湖光铃兰", "need": 20, "have": 12 }
  ]
}
```

## 规则

- **只有一个 `goal`。** 两个等于没有。他要是说了两个，选更急的那个，另一个放进 `blockers` 之外的
  "下次再说"——或者干脆问他一句哪个先做（这是少数值得反问的地方）。
- `blockers` 只留**还没解决**的。解决了就删掉，不要留历史——这不是日志，是当前状态。
- `grind` 只记**正在刷**的材料，不记仓库全量。
- 写之前先 `read` 一次，保留他没提到的字段，只改该改的。**不要整份重写成你猜的版本。**
- 字段名不能改：`cards/progress.card.json` 按名字取值。

## 回答

写完用一句话确认，然后**顺手给一句下一步**：

> 记下了：还差 8 个湖光铃兰，今天树脂够刷两轮。

不要复述整份 JSON，不要列清单。
