# 版本与卡池

## 来源纪律

- 只认官方：官网公告、游戏内公告、官方社媒。攻略站只用来找线索。
- 每条带：**版本号 / 公告日期 / 抓取时间 / 来源链接**。
- 抓不到（无网、页面改版、公告只在游戏内）：直接说"抓不到，你截个游戏内公告我整理"。
  **不要凭记忆写版本内容**——版本改动是最容易被记错的一类事实。

## 落盘

`data/patch/<版本>.md`：

```markdown
# 5.x 要点

- 公告日期：2026-10-18
- 抓取时间：2026-10-31T22:40:00+08:00
- 来源：<官方链接>

## 影响我玩法的

| 改动 | 影响 | 我要改什么 |
|---|---|---|
| 某角色 E 冷却变长 | 循环手感变慢 | 换一个起手顺序 |

## 卡池 / 活动截止

| 内容 | 截止 | 还剩 |
|---|---|---|
| 限定卡池 | 2026-11-05 05:59 | 5 天 |

## 未确认

- 只在攻略站看到、官方公告未见 → 不采纳
```

## 回答

- 只说**影响玩法**的改动，不复述全部补丁说明。
- 每条后面接"所以你要改什么"，没有这句就别写。
- 时间类一律换算成"还剩几天"，别让他自己算。
- 与 `AGENTS.md` 配置里的版本号不一致时先提醒一句。

## 回填

版本号写回 `AGENTS.md` 配置区是**行为配置变更**，先问用户确认。
`data/patch/*.md` 是你的数据，直接写。
