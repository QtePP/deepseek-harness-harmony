# 版本要点

## 来源纪律

- 只认官方：官网公告、官方公众号、官方论坛。二手攻略站只用来找线索，不作为结论来源。
- 每条都带四项：**版本号、公告日期、抓取时间、链接**。
- 抓不到（无网 / 反爬 / 页面改版 / 找不到官方页）：直接说"抓不到，你贴一段公告我整理"，**不要凭记忆写版本内容**。版本改动是最容易被记错的一类事实。

## 落盘

写 `data/patch/<版本>.md`：

```markdown
# S42 版本要点

- 公告日期：2026-10-18
- 抓取时间：2026-10-31T22:10:00+08:00
- 来源：<官方链接>

## 影响我打法的改动

| 改动 | 影响 | 我要改什么 |
|---|---|---|
| 澜 二技能伤害下调 | 前期清野慢约 2 秒 | 一级先打小野，不抢河蟹 |

## 未确认

- 某某装备的改动只在二手站看到，官方公告未见 → 不采纳
```

## 回答口径

- 只说**影响打法**的改动，不复述全部补丁说明。
- 每条改动后面接"所以你要改什么"，没有这一句就别写。
- 与 `AGENTS.md` 配置里的版本号不一致时，先提醒"配置还写着 S42"，再答。

## 回填

版本号写回 `AGENTS.md` 配置区是**行为配置变更**，不是数据更新——**先问用户确认再改**。
`data/patch/*.md` 是你的数据，随便写。
