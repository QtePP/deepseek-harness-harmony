# 原著对照

这是这个 pack 的核心技能。用户问"这是真的吗"，要的不是"是真的"或"是假的"，
而是**"哪一版里有"**。

## 三源表

| 事件 | 演义 / 小说 | 正史 | 本作 |
|---|---|---|---|
| 温酒斩华雄 | 关羽 | 孙坚所斩（《三国志·孙破虏传》） | 待确认 |
| 草船借箭 | 诸葛亮 | 无此事；孙权濡须口乘船受箭（《魏略》） | 待确认 |
| 空城计 | 诸葛亮 | 无；裴松之注引郭冲《三事》，裴本人驳其不可信 | 待确认 |
| 三英战吕布 | 有 | 无 | 待确认 |
| 刮骨疗毒 | 华佗主刀 | 有刮骨事，未载医者名；华佗卒年早于此 | 待确认 |
| 周瑜气量 | 狭小善妒 | "性度恢廓"（《三国志·周瑜传》） | 待确认 |
| 宋江人马 | 一百单八将 | 记载为三十六人（《宋史》），108 将是小说 | 待确认 |

`本作` 那一列永远留空或写"待确认"——**游戏怎么改的，只有玩到那一步的人知道**。

## 怎么用这张表

- 用户问某件事，先在表里找；找到就按三列答。
- 找不到就**不要硬套**，直接说"这条我不确定是哪一版"，然后给方向：
  让他看书里/游戏里的原文，或者查权威辞书。
- 表里没有的条目，宁可说"未确认"，也不要写成确定事实。

## 最容易混的几类

1. **把小说当历史**：上面那张表基本都是这一类。
2. **把戏曲/评书当小说**：青龙偃月刀、方天画戟这类兵器形制，多是后世戏曲和民间说唱加的，
   汉代没有那种长柄大刀。
3. **把游戏当原著**：本作为了玩法会挪时间线、提前出场、合并人物——**这是改编不是错误**，
   别用"这不符合历史"去否定它。
4. **把正史当唯一标准**：他玩的是演义题材游戏，演义才是这个世界的设定。正史只用来解释"差别在哪"。

## 回答口径

不要说"其实历史上不是这样的"——这句话在玩演义游戏的人听来是在拆台。
说"演义里是这样，正史里是那样，你玩的这版可能又不一样"，把三层摆清楚，让他自己选信哪个。
