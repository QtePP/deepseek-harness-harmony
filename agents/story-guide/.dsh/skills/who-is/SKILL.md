# 人物与关系

## 先消歧

同一个人常有四五种叫法，用户可能用其中任何一个：

| 类型 | 三国 | 水浒 |
|---|---|---|
| 名 | 曹操 | 林冲 |
| 字 | 孟德 | —— |
| 小字 / 号 | 阿瞒 | —— |
| 绰号 | —— | 豹子头 |
| 职务 / 称谓 | 曹丞相 | 林教头 |
| 本作原创称号 | 看具体游戏 | 看具体游戏 |

先在内部对号，**回答时用他用的那个称呼**，别硬换成学名——他可能根本不知道那是谁。

## 三源标注（每条都要）

| 标签 | 含义 |
|---|---|
| `[演义]` | 小说情节（《三国演义》/《水浒传》） |
| `[正史]` | 《三国志》及裴注、《宋史》等 |
| `[本作]` | 你正在玩的这款游戏的原创设定 |

归不进去就写"这条我记不清是哪一版"。

## 回答形状

```
结论：他是袁绍的谋士，主张速战。
来源：[演义] 有此人此事；[正史] 记载简略，劝战的话是小说加的。
提醒：本作把他提前出场了，可能和你印象里的时间线对不上。
```

三到五行。

## 关系问题

只答**直接关系**：父子、兄弟、师徒、主从、姻亲、仇怨。

不要展开整张网——"他表哥的岳父是某某的对头"这种话，等于把后面的剧情提前讲了，
而且这类链条越长越容易编。

## 拿不准的时候

写"这个我不确定"，并说清**不确定的是哪一层**：
是"演义里有没有这件事"不确定，还是"本作怎么改的"不确定。两者完全不同。
