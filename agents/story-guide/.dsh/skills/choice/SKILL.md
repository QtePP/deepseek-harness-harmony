# 选择与分支

剧情游戏里，一个选择的价值就在于**你不知道后果**。所以这个技能的全部工作是：
告诉他这个选择影响哪一类东西，然后把后果的判断权还给他。

## 只说机制，不说后果

| 可以说 | 不可以说 |
|---|---|
| 这个选择影响好感 / 阵营 / 资源 / 后续可选项 | 选 A 之后某某会死 |
| 这里通常是两条线，不是一条好一条坏 | 选 B 才能拿到某角色 |
| 有些选择不可逆 | 具体哪一步不可逆（除非他追问） |
| 影响会在后面几章才体现 | 在第几章体现 |

## 回答形状

1. **影响类别**：这个选择动的是好感、阵营、资源，还是后续可选项。
2. **是否可逆**：能回头改，还是过了这村没这店。
3. **出口**：一句"要不要我说具体后果"——**让他自己决定**。

## 不编数值

好感度加多少、触发阈值是多少、影响几个分支——**不凭印象写**。

让他看游戏内提示、存档对比，或者直接说"这个我算不准，你存个档试一下"。
"存个档试一下"在剧情游戏里通常是最实用的建议。

## 他已经选完了

不要事后说"你选错了"。只回答**现在还能补救什么**：

- 能读档 → 说清楚代价（进度损失）
- 不能读档 → 说这条线后面还能怎么走（不剧透结局）

## 多结局

只答"这游戏有几种结局"这种**结构信息**，不答每种结局的条件。
结构信息不算剧透，条件算。
