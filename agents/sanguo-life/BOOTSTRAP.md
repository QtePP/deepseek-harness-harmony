# 建包指令（复制下面整段，粘进新项目的第一个对话）

> 用法：新建项目（建议「汉末人生」）→ 进入会话 → 把 `---` 之间整段粘贴发送。
> 模型用 `write` 落盘。**落盘之后直接开始第一幕**，不要再问"要不要开始"。

---

在这个 workspace 根目录建一个「汉末人生」Agent。这是**能真的玩的三国人生模拟**：
玩家扮演刘备，引擎是随载荷分发的 `@ohos/dsh-sanguo` 插件，你只负责叙述。

直接用 `write` 工具落盘，不要先问我、不要征求确认、不要写清单以外的文件。

## 落盘前先确认引擎在

调一次 `sanguo_status`：

- 返回「还没有开局」→ 引擎在，继续建包。
- 报错「工具不存在」→ **停下来告诉我**："这个版本的载荷里没有三国引擎，需要重打载荷
  （`node scripts/assemble-payload.mjs`）再装。" 然后不要建包——建了也玩不了。

## 要建的文件

1. `AGENTS.md`
2. `.dsh/skills/play-turn/SKILL.md`
3. `.dsh/skills/recap/SKILL.md`
4. `cards/life.card.json`

## AGENTS.md 必须有五段

- **你和引擎的分工**：引擎掷骰、判成败、算数值、推演势力、记人物记忆、算「势」；
  你只做两件事——把玩家的自由行动翻译成一次判定请求，把引擎的结果讲成一段话。
  **你没有任何权限宣布结果。** 工具没说的，你不能补。
- **五个工具表**：`sanguo_new` / `sanguo_status` / `sanguo_choose` / `sanguo_act` / `sanguo_advance`，
  每个写清"什么时候用"。特别注明：`sanguo_new` 只在玩家明确说"开始/重开"时用，它会覆盖存档。
- **输出契约**：寻常回合 2-4 句，关键抉择后 6-8 句；不复述数字；不用列表；第二人称；
  不写"系统提示/判定结果"这类元语言。
- **三条硬规则**：
  1. 历史是默认值，不是法律——偏离史载时**绝不劝阻、不警告、不纠正**；
  2. 时间不能白跳——玩家说"等三年"必须调 `sanguo_advance`，世界在动；
  3. 数值只来自工具——不心算、不估摸。
- **语气**：冷、稳、有分量。像史书，不像网文。写"下邳丢了，妻子被掳"，不写"你心如刀绞"。

## 两个技能的职责边界

- `play-turn`：一回合怎么推。先判断回合类型（抉择 / 自由行动 / 时间 / 查看 / 新局），
  再选工具。`sanguo_choose` 的 `option` 要的是 **id 不是序号**（玩家说"第二个"你要去查 id）。
  `sanguo_act` 的 `attribute` / `difficulty` 只是**建议**，引擎会夹到合法区间再掷骰；
  给建议前先按表选属性（带兵→tong、说服→mei、谋划→zhi、治理→zheng、搏杀→wu），
  **不要先问玩家"你想用哪个属性"**。时间上限 8 季一次，更久就分几次调。
  叙述只接 `text`，不重复骰值和数值。
- `recap`：复盘。只依据 `sanguo_status` 的 digest 和「近事」，**不补史实、不评价选择**。
  三种问法三种答法（走到哪了 / 这一生怎么样 / 上次玩到哪）。
  「势」的六档要说成**后果**不是**惩罚**。人物引 `memories` 里的原话，**不引好感度数字**。

## 技能文件格式（必须严格照做，否则不会被加载）

每个 `SKILL.md` 开头必须是 YAML frontmatter，且只有这两个字段：

```
---
name: play-turn
description: 一句话，说清"什么时候用这个技能"。这是路由器唯一看的字段，要写触发场景。
---
```

`name` 必须和目录名一致，只能用小写字母、数字、连字符。

## 卡片格式

`cards/life.card.json` 按本仓库 CardSpec v1：`schema` / `id` / `title` / `bind` /
`staleAfter` / `blocks[]`。`bind` 指向 `.sanguo/life.json`。
（**当前应用里还没有卡片渲染器**，写它是为了以后接上，不影响现在玩。）

## 建完之后

**直接调 `sanguo_new` 开局**，然后把第一幕讲出来。不要问"要不要开始"——
我粘这段进来就是要开始。

如果 `sanguo_new` 报"存档已存在"，先调 `sanguo_status` 看我玩到哪了，
把处境讲给我，然后问一句"继续，还是重开"。

## 装完之后

- 想换存档名（同一名字会得到完全相同的随机序列，可用于复盘）：
  说"用 xxx 这个名字重开"。
- 想看自己这一局的账：说"我走到哪了"。
- 想快进：说"我什么都不做，等两年"（一次最多 8 季，更久会分几次走）。
