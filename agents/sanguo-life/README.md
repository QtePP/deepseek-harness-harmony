# 汉末人生 · sanguo-life

一个**能真的玩下去**的三国人生模拟：你扮演刘备，从 161 年涿县出生开始，
走完他生命里的十二个岔路口。你可以照史载走，也可以随时离开史载。

**它和本仓库其他 agent pack 不一样的地方**：它带一个真正的裁判引擎
（`@ohos/dsh-sanguo` 插件，随载荷分发），骰子、数值、势力推演全在引擎里，
模型只负责把你做的事讲成一段话。

---

## 为什么引擎必须是插件

这个仓库里其他 pack（`match-coach` / `openworld-guide` / `story-guide`）都是纯文件：
`AGENTS.md` + `skills` + `cards`，零代码。这个 pack 不行，原因是硬的：

> 本 profile 跑 `tools.mode: native`，`run_code` **不在模型工具表里**
> （`dsh-tools` 只在非 native 注入），`bash` 又被 patch 移除（鸿蒙禁 fork/exec）。

所以工作区里放一个 `.js` 引擎 = 一个没有任何东西能执行的文件。
引擎只能随载荷分发成插件，模型通过工具调用它。

**这不是妥协，是正确分工**：引擎当裁判，模型当说书人，两者在一个窄的、
可校验的接口上会合。

## 长什么样

```
你：开始
它：（开局）161年·春 · 0岁 · 第一幕·涿郡
    舍东南角篱上有桑树生高五丈余，遥望见童童如小车盖。
    你与同宗诸儿戏于树下。

你：我要说那句话
它：（调 sanguo_choose { option: 'say_it' }）
    你指着那棵树说：吾必当乘此羽葆盖车。
    叔父刘子敬当场变色，喝你住口。
    此事后来被人记住——虽然记的是"这孩子狂"，不是"这孩子有志"。
```

```
你：我在督邮这件事上不忍，交印走人
它：（调 sanguo_choose { option: 'endure' }）
    你把印绶放在案上，没有多说一句，转身出门。
    督邮在背后笑了一声，你没有回头。
    出门时关羽看了你一眼，什么也没说。
    （势 → 10，略有风闻：此选偏离史载）
```

```
你：我什么都不做，在新野待三年
它：（调 sanguo_advance { turns: 8 }，两次）
    这三年里曹操平了河北，又南下了荆州。
    刘表病死在襄阳，刘琮接了州，第一件事就是遣使向曹操请降。
    你在新野，什么也没做，等你抬头时，曹操已经在路上了。
```

注意第三段：**玩家不行动，世界照样走**。这是这个 pack 的核心设定。

## 玩法：两种判定，两种人生

引擎里有两套完全不同的机制，对应刘备一生里两种完全不同的时刻：

| | 能力判定 | 仁义抉择 |
|---|---|---|
| 什么时候 | "我能不能做到" | "我愿意付什么代价" |
| 掷骰 | **掷**（1d100 + 属性 + 修正） | **不掷** |
| 结果 | 大成功 / 成功 / 勉强 / 失败 / 大败 | 选项写死，代价写死 |
| 谁决定 | 骰子 | 玩家 |

**为什么分开**：如果把"携民渡江"也做成掷骰，那这个游戏讲的就是运气，不是人。
历史上它没有失败——它让他失去了一切物质，却在十年后买回了荆州和益州。

---

## 三个计数器（这才是这个游戏的主角）

刘备一生丢了至少三次地盘，但**三样东西基本只涨不跌**：

| 计数器 | 含义 | 涨 | 掉 |
|---|---|---|---|
| **名望** | 天下人怎么议论你 | 救孔融、让徐州、携民渡江 | 背信、屠城、反复 |
| **信义** | 跟着你的人信不信你 | 失败时不弃部下 | 为利翻脸 |
| **人才** | 谁愿意来、来了留不留 | 声望到阈值自动触发 | 信义崩了，人会走 |

**前二十年他一直在攒这三样，最后十年才兑现。** 这是这个游戏想让玩家自己发现的东西。

---

## 「势」：偏离史载的代价

你说"扮演模式，可以偏离"，那历史就不能是墙，只能是价。

```
偏离一次史载  → 势 +10
实力不足硬来  → 势 +（缺口 × 0.5）
一季无所作为  → 势 −2
```

`势` 转化为**判定惩罚**（上限 −30），并改变天下对你的看法：

| 势 | 天下 |
|---|---|
| 0 | 天下未觉 |
| <15 | 略有风闻 |
| <35 | 人多侧目 |
| <60 | 四方疑之 |
| <85 | 天下共疑 |
| ≥85 | 举世皆敌 |

**关键：它永远不否决你。** 一个把「势」拉满的玩家面对的是一个处处与他为敌的世界，
但世界仍然是可以玩的。这是模拟和轨道的区别。

---

## 世界不等你

每季（一回合 = 一季）引擎独立推演一次势力：

- 强弱悬殊（2.4 倍以上）且**接壤**的势力会取地（`ADJACENCY` 表，11 个州）
- 各势力的本州（`home`）防御力更高，不容易被一口吃掉
- 势力按史实年份出场与退场（孙权 200 年才登场，董卓 192 年后消失且失地）
- 无地的势力会掉实力——一个没有地盘的军阀就是流寇

所以在新野坐等五年，曹操照样统一河北、刘表照样病死、刘琮照样投降。
**玩家不在场，历史照走。**

## 怎么装

### 前提：载荷里有引擎

```bash
node scripts/assemble-payload.mjs        # 约 30 s
bash scripts/deploy.sh                   # 装到真机
```

引擎已经挂在 `ohos` profile 里（`@ohos/dsh-bundle-ohos` 的 insert 行 `sanguo-ohos`）。

### 玩法：在应用里建一个项目

1. 新建项目（建议叫「汉末人生」），进入它的会话；
2. 把 `BOOTSTRAP.md` 里 `---` 之间的那段粘进去发送；
3. 模型落盘 `AGENTS.md` / `.dsh/skills/` / `cards/`，然后开始第一幕。

或者开发者路线：把本目录**内容**上传到 `.../files/workspaces/<projectId>/`。

## 目录

| 路径 | 作用 | 谁改 |
|---|---|---|
| `AGENTS.md` | 人格 + 工具契约 + 输出契约 | 用户（改行为要确认） |
| `.dsh/skills/play-turn/` | 一回合怎么推：三种回合类型 → 三个工具 | 用户 |
| `.dsh/skills/recap/` | 复盘：只讲已发生的，不评价选择 | 用户 |
| `cards/life.card.json` | 这一局的状态投影（**当前应用内还没有卡片渲染器**） | 用户 |
| `agent.json` | pack 元数据 | 用户 |

引擎本体在 `host/profile-ohos/.../@ohos/dsh-sanguo/`。

## 已知没做

- **卡片还看不见。** 和其他 pack 一样，`cards/life.card.json` 是给 CardRenderer 的契约，
  应用里还没有渲染器。数据链路是真的，只是没人读。
- **第八至十二幕未写。** 引擎支持，内容是空的。走到第七幕末尾会停在"这一段落已尽"。
- **没有 NPC 对话工具。** 人物有态度和记忆，但没有 `sanguo_talk`——
  对话目前由模型基于 digest 里的人名与记忆来讲，不落状态。这是有意的：
  先验证"判定 + 势力"这条主干，再考虑把对话也变成机制。
- **没有存档管理 UI。** 存档在 `.sanguo/save.json`，可以手改、可以拷走，
  但应用里没有"读档/多周目"的入口。

## 验收（装完自己点五下）

1. 发「开始」→ 出现 161 年、0 岁、桑树，**不是 184 年 23 岁**。
2. 发「我要说那句话」→ 工具轨迹一步（`sanguo_choose`），叙述里没有骰值和数值。
3. 发「我不杖他，交印走」→ 明确说出这是偏离史载，且**没有劝阻你**。
4. 发「我什么都不做，等两年」→ 天下出现势力变化，时间真的走了。
5. 杀掉 app 重进 → 发「我走到哪了」，年月和场景还在。

第 1 条和第 3 条是这个 pack 的核心：**年代对得上，偏离不被拦。**
