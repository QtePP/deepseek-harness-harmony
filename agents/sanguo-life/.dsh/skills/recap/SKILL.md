# 复盘

## 只讲已经发生的事

复盘的数据来源只有两个：`sanguo_status` 返回的 digest，和它里面的「近事」。

**不要**补史实、不要补"历史上他这时候应该……"、不要评价玩家的选择对不对。
玩家问的是**他这一局**，不是刘备的一生。

## 三个问题，三种答法

### "我走到哪了"

按这个顺序，四到六行：

```
现在：<年月>，你 <年龄> 岁，在 <地点>。
身份：<titles>
本钱：兵 <troops>，金 <gold>，粮 <grain>。
三样攒下的：名望 <fame>，信义 <trust>，人才 <talent>。
天下：<world.mood>。
```

然后**一句**判断，说清他现在的处境属于哪一类：

| 处境 | 判据 | 一句话 |
|---|---|---|
| 有本钱没地盘 | 兵多、无 titles | "你手里有人，但还没有一块自己的地方。" |
| 有地盘没本钱 | 有 titles、兵少 | "你有名分，但守不住它。" |
| 两者皆无 | 兵少、无 titles | "你什么也还没有。这正是最难的时候。" |
| 三样在涨 | fame/trust/talent 高 | "你的地盘不稳，但跟着你的人越来越多。" |

### "这一生怎么样"

这不是问剧情，是问**账**。按四段讲：

1. **你做过几个偏离史载的选择**（`deviations`）。这是这一局的性格。
2. **三样攒下了多少**（名望 / 信义 / 人才）。这是复利。
3. **天下现在什么局面**。这是背景。
4. **一句话**：你在往哪走。

不要写成爽文总结。刘备的账是**前二十年看着一直在输**，你要如实说。

### "上次玩到哪"

只讲「近事」里最后两三条，加上当前场景。不要展开。

## 势：偏离史载的代价

`sanguo_status` 的 digest 第三行有 `势 <drift>（<mood>）`。这是**偏离史载的代价**，
不是你的力量。你的力量叫**实力**，在第一行。

混用这两个词会让玩家以为"势越高越强"，而实际正好相反：

| drift | mood | 怎么说 |
|---|---|---|
| 0 | 天下未觉 | "没人觉得你反常。" |
| <15 | 略有风闻 | "有些人在议论你。" |
| <35 | 人多侧目 | "你做的事开始让人不安。" |
| <60 | 四方疑之 | "各方都在重新估量你。" |
| <85 | 天下共疑 | "你已经不在任何人的计划之内了——他们都在防你。" |
| ≥85 | 举世皆敌 | "天下没有你的位置了。你只能自己打出来。" |

**这是后果，不是惩罚。** 不要用"你错了"的语气讲它。

## 人物

`sanguo_status` 返回的 `people` 里有每个人对你的 `stance` 和 `memories`。

讲人物时**引记忆，不引数字**：

> ✅ "曹操记得你在酸枣替他挡过一次追兵。"
> ❌ "曹操对你的好感度是 +12。"

记忆是引擎记下的事实，可以直接引用；数字是内部量，讲出来就变成攻略表了。

## 不要做的事

- ❌ 评价"你选得好/不好"
- ❌ 说"如果当初……"——这一局没有如果
- ❌ 剧透还没到的章节
- ❌ 把 `deviations` 说成"错误"
- ❌ 没有存档时说"你还没开始"就完事——要顺手告诉他怎么开一局
