TA Harness 隐私政策

应用名称：TA Harness　·　包名：com.qtepp.taharness　·　开发者：陈景翀（个人开发者）
生效日期：2026 年 10 月 31 日

本政策说明 TA Harness（下称「本应用」）如何处理你的数据。本应用的设计原则是： 所有数据保存在你的设备本机，应用本身不收集、不上传任何用户个人信息。

1. 我们不收集什么

  • 无账号系统：无需注册、登录，不持有你的任何身份信息；
  • 无数据收集组件：不内置任何统计、埋点、崩溃上报、广告或推送 SDK；
  • 不上传使用记录：会话内容、使用习惯不会发送给开发者或任何第三方统计服务。

2. 本机存储了什么

以下数据全部保存在设备本机的应用沙箱目录内，仅你可访问：

  • AI 会话记录：你与 AI 的对话、生成的文件，按会话保存在本机；
  • 项目与设置：你创建的项目、能力开关等偏好；
  • 模型 API Key：你自行填写的模型服务密钥（如 DeepSeek API Key），仅保存在本机沙箱文件中，不会上传到开发者的任何服务器。

3. 权限使用说明

  • 网络访问（INTERNET）：用于调用你配置的模型 API、AI 工具访问网页；
  • 获取网络状态（GET_NETWORK_INFO）：用于判断当前网络可用性，提示连接状态；
  • 文件访问授权（FILE_ACCESS_PERSIST）：仅记住你主动授权给应用的目录，用于 AI 读写工作区文件与文件预览。你未授权的目录应用不会访问。

4. 第三方服务

  • 模型服务：本应用的 AI 能力来自模型服务 API（默认支持 DeepSeek，需你自行注册并提供自己的 API Key）。你与 AI 的对话内容会从设备直接发送到对应模型服务商（如 api.deepseek.com），其数据处理受该服务商隐私政策约束，详见 DeepSeek 官网；
  • 网页访问：使用 AI 内置的网页搜索 / 网页读取工具时，应用会从设备向目标网站发起请求；
  • AI 运行时：AI 运行时完全在设备本机进程内运行，不连接开发者服务器，不经任何中间人转发。

5. 数据的存储与安全

本应用不将你的数据存储到云端。API Key 以仅应用可读的沙箱文件形式保存在本机。 设备丢失或应用被卸载时，上述数据随沙箱一并清除。

6. 如何删除数据

  • 在应用内可随时删除会话与项目；
  • 卸载应用即彻底删除本应用保存在本机的全部数据（含 API Key）。

7. 未成年人

本应用不面向未成年人提供，未成年人应在监护人指导下使用。

8. 政策更新

政策内容如有变更，将在本页面更新并修订生效日期。
